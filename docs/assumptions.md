# Реестр допущений и открытых вопросов

Все пункты ниже — решения, которых нет в явном виде в текстах `Documentation` (Приказ № 343 с Приложениями,
СП РК 2.04-103-2013, СО 153-34.21.122-2003, ТР ТС 028/2012, ППБ № 55).
Перед подачей проекта на экспертизу их должен подтвердить инженер.

## Безопасные расстояния (Приложение 11)

1. **Коэффициент из диапазона таблицы 2.** По умолчанию берется максимум диапазона (Приказ: «чем прочнее объект,
   тем меньшее значение»; максимум — для наименее прочного объекта, в запас). Для конкретного объекта
   коэффициент задается полем `custom_kv_override`.
2. **Полууглубленные необвалованные хранилища** для УВВ и передачи детонации считаются открытыми зарядами
   (в запас); «углубленными на свою высоту» считаются только `location_type = buried` и обвалованные.
3. **Подземные хранилища** главами 3–4 Приложения 11 не рассчитываются — выдается ошибка расчета.
4. **Активный заряд из разных ВМ.** п. 19 регулирует только пассивный заряд; для активного принимается
   наибольший Kд по всем ВМ хранилища, масса — суммарная.
5. **Детонирующий шнур (п. 20: 1 м = 10 детонаторам).** Пользователь задает массу ВВ шнура с учетом этого правила
   и класс `detonators`; длина шнура в модели не хранится.
6. **«Расположенные по одной оси» хранилища (п. 17)** — оба вытянуты вдоль одной оси координат, их проекции
   на перпендикулярную ось перекрываются. Повернутые хранилища не поддерживаются.
7. **Противопожарные разрывы (п. 17, абзац 2)** и **суммарный запас при сближении (п. 17, абзац 3)** не рассчитываются.
8. **Таблица 3** внесена как альтернативный метод (`settings.uvv_method = "table_3"`; п. 10, подпункт 7 —
   «могут приниматься»). По умолчанию остается таблица 2. Расчет — по формулам строк (в шести ячейках
   500–2000 кг формула больше таблицы на 5–12 %, в запас). Для «объектов 3» и открытого хранилища, а также
   при Q > 250 т таблица неприменима — ошибка расчета (нужна таблица 2). Обвалованные хранилища относятся
   к строке «углубленные (обвалованные)»; коэффициент рельефа к таблице 3 не применяется.
9. **ЛЭП.** Примечание к таблице 2 указывает считать расстояние до ЛЭП по разлету кусков, а не по УВВ; разлет
   в ядре не реализован — в демо-проекте ЛЭП оставлена как объект УВВ для иллюстрации.

## Генплан

10. Тип склада для норм ограды берется по наиболее строгому сроку эксплуатации хранилищ
    (постоянный → временный → кратковременный).
11. Для кратковременного склада проверяются только нормы п. 621; запретная зона 50 м (п. 590) к нему не применяется.
12. Зона запрета открытого огня 100 м (п. 16) на генплане строится от контура хранилищ.

## Перевозка (п. 74)

13. Если состав груза не задан, правило 2/3 грузоподъемности проверяется в запас.

## Обвалование

14. Защитный вал примыкает внутренней подошвой к внешней подошве главного вала; линия визирования п. 605 проводится
    от угла здания через внутреннюю бровку гребня главного вала у разрыва.
15. Отступ подошвы вала от стены, ширина проезда, перекрытие защитного вала и угол откоса — проектные параметры
    (задание № 4), нормой не ограничены.

## Молниезащита

16. **Метод и уровень по умолчанию** — катящаяся сфера СП РК 2.04-103-2013, уровень защиты I (D = 20 м),
    решение инженера. Ни СП РК, ни СО 153 не закрепляют уровень для складов ВМ прямо.
17. **Надежность по СО 153** — 0,999 (максимум диапазона 0,9–0,999 для специальных объектов, п. 2.2).
    При ней мачты заметно выше, чем по сфере уровня I (в демо: одна мачта — ~28–32 м против ~10–12 м).
18. **Расстояния 5 м (мачта — стена) и 3 м (заземлитель — вход)** — проектные значения задания № 4
    (статус `design_default`), не нормативы: в СП РК, СО 153, РД 34.21.122-87 и ПУЭ РК их нет.
    Проверка 5 м по-прежнему выдает нарушение `LIGHTNING_MAST_TOO_CLOSE_TO_STORAGE`; 3 м в расчетах не используется. СП РК п. 9.3 отсылает к табл. 15 ПУЭ, но в ПУЭ РК это таблица токов кабелей;
    РД, п. 2.3 задает расстояние Sв от 3 м по сопротивлению грунта и типу заземлителя
    (`docs/norms_verification.md`, «Задание № 10»).
19. **Несколько мачт** проверяются как объединение одиночных зон (в запас); формулы двойного
    стержневого молниеотвода (СО 153, п. 3.3.2.3, табл. 3.6) пока не реализованы.
20. **Зоны А и Б РД 34.21.122-87** оставлены для старых файлов проекта (только `zone_type`); формулы сверены
    с Приложением 3, п. 1.1, но по вводной части РД не распространяется на здания, связанные с хранением ВВ.
21. **П. 691 для подземных хранилищ** не проверяется (п. 686: при толщине покрытия более 10 м не оборудуется;
    толщина покрытия в модели не хранится).

## Классификация ВМ (ТР ТС 028/2012)

22. Шифр проверяется только при заданном `hazard_subclass`; для группы C шифры в Приложении 3 не указаны —
    не проверяется. Группа A (есть в модели с этапа 1) дает нарушение: в ТР ТС ее нет.

## Прочие проектные значения

23. Запас 0,5 м над грузом до потолка, зазор 0,02 м между местами тары, толщина полки 0,04 м,
    толщина стен 0,40 м — значения заданий, не нормы.
24. Тротиловый эквивалент выводится в записке только справочно; в расчетах Приложения 11 не участвует.

## Молниезащита и генплан (этап 14)

25. **Точки кровли вне зоны защиты.** Если раздел молниезащиты задан, но хотя бы одна из семи контрольных точек
    (углы карниза, торцы конька, верх вентшахты) вне зоны защиты, требование п. 691 считается невыполненным —
    нарушение `LIGHTNING_ZONE_NOT_COVERED`. Для кратковременных (п. 693) и подземных хранилищ защита не обязательна,
    поэтому выдается только замечание расчета.
26. **Генплан на чертеже и в предпросмотре** строится по проектным расстояниям (ограда — хранилище, запретная зона,
    зона огня, караульное помещение, навес для тары). Не заданное расстояние заменяется нормативным минимумом
    для типа склада; для кратковременного склада незаданные запретная зона и навес для тары не рисуются
    (см. п. 11). Положение ПРП на генплане условное.
