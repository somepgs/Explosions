# План работ (ROADMAP)

Единый список задач проекта `explosions-core`. Любая сессия, в том числе новая, начинает отсюда: берет задачу
по идентификатору, выполняет ее по правилам ниже и обновляет статус. Состояние на 11.11.2026; последние изменения —
в `git log`.

**Очередь:** A0 → A2 → E0 → E1 → E2 → остальное по приоритетам. Параллельно с ними — задачи из других групп конфликтов.

## Как работать с планом

- **Статусы:** «открыта» → «в работе (ветка, сессия)» → «сделана (коммит)». Сделанные задачи переносятся
  в раздел «Сделано» с хешем коммита.
- **Одна задача — одна ветка и одна сессия** (свежий контекст). Сессия-оркестратор пишет бриф со ссылкой
  на идентификатор задачи, проверяет результат (дифф, сверка с PDF, тесты), вливает в `main` перемоткой
  (fast-forward) и отправляет на GitHub по просьбе пользователя.
- **Параллельно** запускаются только задачи из разных групп конфликтов (раздел ниже). Задачи группы «Нормы»
  выполняются строго по очереди.
- **Готово, когда:**
  - сначала написан тест, затем код (CLAUDE.md, п. 4);
  - весь набор тестов зеленый: `.\.venv\Scripts\python.exe -m pytest` после `uv sync --extra dev --extra gui`,
    либо без изменения `.venv`: `uv run --no-sync --with pytest --with pyside6-essentials python -m pytest -q`;
  - новые нормативные значения — константы в `norms/constants_rk343.py` с пунктом НПА и записью в `norms/sources.py`;
    ссылки на пункты — из `norms/references.py`;
  - решения, которых нет в тексте НПА, записаны в `docs/assumptions.md`, сверка — в `docs/norms_verification.md`;
  - статус задачи в этом файле обновлен.
- **Нормы — только по тексту PDF в `Documentation`.** Если нужной формулы или таблицы нет в тексте, задача
  останавливается с вопросом пользователю (CLAUDE.md, п. 1 и 4), значение не придумывается.
- **Нормы РФ** (в том числе РД 34.21.122-87 и СО 153-34.21.122-2003) — не нормативное основание в РК
  (CLAUDE.md, п. 1; методика ГИП, раздел 2). Допустимы только как методика с пометкой «ПРЕДВАРИТЕЛЬНО,
  не нормативный расчет» и после проверки, что не противоречат норме РК.
- **Статус НТД РК:** СН РК и СП РК — по АГСК-1 и «Изменениям в АГСК-1», ГОСТ — по КазСтандарту, НПА — по adilet;
  реквизиты, статус и дата проверки — в `docs/norms_verification.md`.

## Открытые вопросы к инженеру

1. **Катящаяся сфера.** Формула (2-1) СП РК применена буквально: h — высота над защищаемой поверхностью
   (`h' = h − hx`). Для отдельно стоящей мачты это дает намного больший радиус, чем геометрическое построение
   катящейся сферы: при h = 12 м, hx = 7,5 м, D = 20 м — около 12,6 м против 2,7 м. Подтвердить толкование
   или добавить проверку в запас.
